FAQ

Questions, answered.

Is this safe for my Facebook account? ⌄
Amplr uses human-like delays, randomized timing, and cooldown protection to mimic natural behavior. The AI rewrite ensures no two posts look identical. Like any automation tool, use it within reason.
Does Amplr store my Facebook password? ⌄
Never. Amplr is a Chrome extension that runs entirely in your browser using your active Facebook session. No credentials are stored or transmitted anywhere.
What is AI paraphrasing and do I need an API key? ⌄
Amplr uses a local AI model (Ollama + qwen3) to rewrite your post uniquely for each group. It runs on your own machine — no API key, no monthly AI cost, completely free.
What happens if my computer is off when a post is scheduled? ⌄
Amplr queues all scheduled jobs in the cloud. As soon as Chrome opens again, the extension picks up any missed posts and fires them immediately.
How many groups can I post to? ⌄
As many as you're a member of. Amplr syncs all your Facebook groups automatically with one click.
